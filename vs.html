Inspecting a live page

A rendered t looks like a t whether it carries 0 hidden codepoints or 28. Paste this into the browser console on any page. It reports the longest run of selectors on any single node — an isolated one is just an emoji, a run of dozens is a payload.

Isolated selectors are almost always U+FE0F doing its ordinary job — forcing colour emoji presentation. Any page with icons has dozens. What matters is the run length: a payload puts many selectors back to back on one node, so a longest run of 1 means the renderer stripped yours.
